# SRC-04 — Described current-state process

Scenario date: 2026-10-06. Source: fictional desk walkthrough notes. This is not production observation evidence.

## P01 — Request and decision

1. Member emails an equipment name and desired dates.
2. Coordinator checks the shared spreadsheet manually.
3. If it appears free, coordinator adds the member's name and replies with confirmation.
4. If unavailable, coordinator replies asking for another date; no waiting list exists.
5. Pending emails are not consistently recorded. Two coordinators can check before either saves a booking.

## P02 — Handover

1. Member arrives; coordinator looks up the booking and checks a separate membership list.
2. If membership appears inactive, coordinator asks a manager. Overrides are not documented consistently.
3. Coordinator writes the actual collection time in the spreadsheet.
4. Walk-in loans sometimes bypass the booking sheet; their future scope has not been decided.

## P03 — Return and exceptions

1. Coordinator records return time.
2. If damage is noticed, coordinator adds a note and physically sets the tool aside.
3. A manager decides when it can go back on the shelf; the sheet has no consistent unavailable indicator.
4. Each morning a coordinator informally checks old rows and emails selected overdue borrowers. No standard threshold or escalation rule is documented.
